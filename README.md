# Nocleg-Finder

Unterkunftssuche für Montageteams nahe der Baustelle (PL/DE).

Adresse der Baustelle, Anreise/Abreise, Anzahl Mitarbeiter, Schlafzimmer, Bäder, Umkreis und Budget pro Nacht und Monteur eingeben – die App erstellt fertige, gefilterte Suchen auf Booking.com, Airbnb, FeWo-direkt, Holidu, HRS, Google Maps, regionalen Portalen und Monteurzimmer-Portalen sowie eine fertige Anfrage an den Vermieter.

Ohne API-Schlüssel und ohne Kosten. Standort per OpenStreetMap (Nominatim).

Öffnen: `index.html` im Browser.
