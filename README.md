# Nocleg-Finder

Unterkunftssuche für Montageteams nahe der Baustelle (PL/DE).
**App:** https://maciejwwymiata.github.io/nocleg-finder/

Adresse der Baustelle, Anreise/Abreise, Anzahl Mitarbeiter, Schlafzimmer, Bäder, Umkreis und Budget pro Nacht und Monteur eingeben – die App erstellt fertige, gefilterte Suchen auf Booking.com, Airbnb, FeWo-direkt, Holidu, HomeToGo, HRS, Google Maps, regionalen Portalen und Monteurzimmer-Portalen sowie eine fertige Anfrage an den Vermieter.

## Rechtliches / Datenschutz
- Kein Server, keine Cookies, keine Analyse. Gespeichert werden nur die letzten Einstellungen im Browser (localStorage).
- Keine externen Schriften (keine Google Fonts) – es werden Windows-Systemschriften verwendet.
- Kein Auslesen (Scraping) von Portalen: Die App erzeugt nur Links zu den öffentlichen Suchseiten. Gebucht wird beim Portal.
- Standortbestimmung über OpenStreetMap Nominatim: eine Anfrage pro Suche, Ergebnis lokal zwischengespeichert, Quelle wird angezeigt (© OpenStreetMap-Mitwirkende).
- Ohne API-Schlüssel und ohne Kosten.

## Installation
Seite in Microsoft Edge öffnen → Menü „…“ → Apps → „Diese Seite als App installieren“.
